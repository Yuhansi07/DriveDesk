Running on Windows:
1. Stop any old backend and Flutter servers (Ctrl+C in their terminals).
2. Extract this ZIP to a NEW folder to avoid copying old screens.dart.
3. Open the DriveDesk_Pro folder in VS Code.
4. Terminal A: npm start
5. Terminal B: cd flutter_app
   flutter pub get
   flutter run -d chrome --web-port=8080 --dart-define=API_BASE_URL=http://127.0.0.1:3000
6. Open http://localhost:8080

If port 3000 is already in use, stop the OLD DriveDesk server first.
